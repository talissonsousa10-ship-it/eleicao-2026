# Imagem de prévia do link (docs/previa.png)

É a imagem que aparece quando o endereço do site é compartilhado (WhatsApp, X, Instagram etc.), com 1200 × 630 pixels.
Para gerar de novo: `npm i @fontsource-variable/archivo @fontsource/martian-mono playwright`, depois `node shot.js`
nesta pasta, e copie `previa.png` para `../../docs/`.
